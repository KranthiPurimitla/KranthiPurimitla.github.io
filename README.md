# Kranthi Purimitla | Observability Engineer

Personal portfolio featuring Dynatrace Extension 2.0 case studies, experience, certifications and recognition.

## Publishing

GitHub Pages serves the root of the `main` branch at https://kranthipurimitla.github.io/. The site uses plain HTML, CSS and JavaScript and requires no build step.

## Change the profile photo

Export a 4:5 portrait as JPEG with the face centered, ideally around 608 × 760 px. In GitHub, choose **Add file → Upload files** and upload the replacement as `profile.jpg` in the repository root. Commit the change to `main`. Once Pages finishes publishing, refresh the site. A “KP” monogram appears when the image is unavailable.

## Maintain credentials and projects

Edit `index.html` to update case studies or issuer links. For a renewed credential, update its issue date, visible status and expiry date, including the `datetime` and `data-expiry` values. JavaScript updates expiry labels after the last valid day. The displayed dates remain readable without JavaScript.

## LinkedIn

From your LinkedIn profile, open **Contact info → Edit → Add website**, paste the public HTTPS URL, choose the website type and save.
